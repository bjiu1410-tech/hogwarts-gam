# TS 말포이: 은빛 운명

**해리 포터 시점**으로 원작 1~7권을 따라가며, 원작 성격 그대로의 오만하고 독설가인
**여자 드레이코 말포이(TS)** 와 라이벌에서 연인이 되어 가는 **비공식·비영리 2차 창작 도트 게임**입니다.

- 1~7학년 원작 흐름을 따라가는 8개 장 + 엔딩 3종 (드레이코 / 라이벌 / 노멀)
- 탐험(도트 맵 이동) + 비주얼노벨 대화 + 선택지에 따른 호감도(드레이코·헤르미온느·론)·용기 수치
- **직접 쓰는 마법 19종**: 루모스·윙가르디움 레비오사·알로호모라·인센디오·엑스펠리아르무스·이모빌러스·레파로·아라니아 엑숨아이·리디큘러스·익스펙토 페트로눔·아씨오·스투페파이·리덕토·디핀도·아구아멘티·프로테고·페트리피쿠스 토탈루스·레벨리오·레비코르푸스 (+ 플리펜도)
- **마법 학습**: 수업·친구·책에서 주문을 배울 때마다 지팡이 동작 따라 하기 + 주문 외우기 타이밍 미니게임
- **플레이 가능한 던전**: 지하 함정(악마의 덫·화로 퍼즐), 픽시 수업, 거미 숲, 비밀의 방 하수관(바위 퍼즐), 보가트 수업, 호숫가 디멘터, 트라이위저드 미로, DA 표적 연습, 신비부·말포이 저택·호그와트 전투
- **자유 시간**: 학년마다 호그와트(복도·대연회장·도서관·그리핀도르 휴게실·화장실·교정·금지된 숲·숨겨진 방)를 자유롭게 돌아다니며 비밀 상자, 개구리 초콜릿 카드, 주문책 찾기
- 미니게임: 빗자루 비행(기억구슬 / 스니치 / 악마의 화염), 마법 결투, 마법약 조제, 무도회 리듬
- 자동 저장 · 장 선택 · 설정(글자 속도, 음악, 효과음)

## APK 받기
어느 브랜치든 푸시하면 GitHub Actions가 APK를 빌드합니다.
저장소의 **Releases** 페이지에서 최신 `ts-malfoy.apk`를 휴대폰으로 받아 설치하세요.
(처음 설치할 때 '출처를 알 수 없는 앱' 설치를 허용해야 합니다.)

## 조작
| | 휴대폰 | 키보드 |
|---|---|---|
| 이동 / 선택 | 왼쪽 십자키 | 방향키, WASD |
| 결정 / 대화 넘기기 | A, 화면 터치 | Z, Enter, Space |
| 빨리 넘기기 / 달리기 | B 누르고 있기 | X, Shift |
| 주문 시전 | ✦ 버튼 | C, J |
| 주문 바꾸기 | ⇄ 버튼 (또는 메뉴 → 주문책) | V, K, Tab |
| 메뉴 | ≡ 버튼, 뒤로 가기 | Esc, M |

## 구조
```
app/src/main/assets/www/   게임 본체 (HTML5 Canvas, 외부 라이브러리 없음)
  js/story.js               시나리오 (문법은 파일 상단 주석 참고)
  js/maps.js                도트 맵
  js/art.js                 캐릭터·타일·초상화 도트 생성기
  js/minigames.js           미니게임 (주문 학습 포함)
  js/magic.js               주문·시전·적·맵 퍼즐·자유 시간 맵 연결
  js/engine.js              스크립트 실행기, 탐험, UI
  img/                      직접 그린 일러스트 (ILLUSTRATIONS.md 참고)
app/src/main/java/...       WebView로 게임을 띄우는 안드로이드 껍데기
```
PC 브라우저에서 `app/src/main/assets/www/index.html`을 열면 바로 테스트할 수 있습니다.
`index.html?test`로 열면 선택지를 자동으로 고르며 끝까지 돌려 보는 테스트 모드가 됩니다.
